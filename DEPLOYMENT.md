## 🚀 How to Deploy on Netlify (FREE)

### Option 1: Drag & Drop (Easiest)

1. Go to [https://app.netlify.com/drop](https://app.netlify.com/drop)
2. Drag the entire `UpConstruction-main` folder onto the page
3. Done! Your site is live in seconds

### Option 2: GitHub + Netlify (Recommended)

1. Create a GitHub account (if you don't have one)
2. Upload your website folder to a new GitHub repository
3. Go to [https://netlify.com](https://netlify.com) and sign up (free)
4. Click "Add new site" → "Import an existing project"
5. Connect your GitHub account
6. Select your repository
7. Click "Deploy site"

## 📧 Form Submissions

Your forms are now using **Netlify Forms** (FREE):
- Quote form on homepage
- Contact form on contact page

### How to receive form submissions:

1. After deploying, go to your Netlify dashboard
2. Click on your site → "Forms" tab
3. You'll see all form submissions there
4. Set up email notifications:
   - Go to Site settings → Forms → Form notifications
   - Add your email: freecoatpaintingsdecor@gmail.com
   - You'll receive emails when someone submits a form!
